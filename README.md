# Project moved to Coloded/tetris

The maintained Python games now live at **[Coloded/tetris](https://github.com/Coloded/tetris)**.

This repository is no longer maintained. Its previous source code and screenshots
remain available in Git history.

## Get the current version

```bash
git clone https://github.com/Coloded/tetris.git
cd tetris
python3 tetris.py
```

For the runner:

```bash
python3 dino.py
```

Requirements, controls and screenshots are in the [new README](https://github.com/Coloded/tetris#readme).
